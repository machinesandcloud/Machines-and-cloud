Does the job need an answer, an action or both?

Finding a source and changing a record are different jobs. Start with what the user needs finished, then choose the retrieval, tools and approvals that fit.

Start with retrieval when

  • The user mainly needs grounded answers
  • There are no meaningful system side effects
  • The useful result is an answer with a source to check

Evaluate tools and actions when

  • The task includes a system lookup or a change to a record
  • Approvals and action controls matter
  • Performance depends on multi-step decisions across tools
